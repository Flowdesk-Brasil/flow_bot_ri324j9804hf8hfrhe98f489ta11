FlowDesk Whitelist Agent
=========================

1. Rode start.cmd (Windows) ou start.sh (Linux/VPS).
2. Cole o ID publico e o token gerados no dashboard (Banco / Mapping).
3. Informe o banco LOCAL (quase sempre host 127.0.0.1, porta 3306).
4. Clique em Testar banco local e depois Conectar na FlowDesk.
5. Deixe esta janela aberta. A FlowDesk nao precisa da porta 3306 aberta na internet.

O IP publico aparece so para conferencia. No modo Agent ele nao vai no campo de host do dashboard.
